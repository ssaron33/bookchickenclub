# 북치킨클럽 v0.9.1 — 게시판 제목 목록 디자인

v0.9.0의 기능과 데이터 구조는 유지하고, 게시판 목록을 디시인사이드와 비슷한 제목 중심의 간결한 목록형 레이아웃으로 바꾼 UI 업데이트입니다.

## 변경 사항

- 게시글 목록에서 본문 미리보기와 카드형 UI 제거
- 제목만 한 줄 목록으로 표시하고 제목 옆에 댓글 수를 `(3)` 형식으로 표시 (`(0)` 포함)
- 작성자와 작성 날짜·시간을 오른쪽 정렬
- 공지는 목록 상단 고정, 일반 게시글은 최신 작성 시각순 유지
- 카테고리 필터, 검색, 게시글 상세 화면, 댓글, 관리자 공지 등 v0.9.0 기능 유지
- 모바일에서는 제목 옆 메타 정보가 좁은 화면에 맞게 배치됨
- 정적 파일 및 서비스 워커 캐시 버전을 `0.9.1`로 통일

## 적용 방법

**이번 버전은 화면 디자인만 수정하므로 Google Apps Script의 `Code.gs` 교체, Google Sheets 마이그레이션, Apps Script 재배포가 필요하지 않습니다.**

1. ZIP의 `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.json` 다섯 파일을 GitHub Pages 저장소의 기존 프론트엔드 파일과 교체합니다.
2. 변경 사항을 커밋합니다.
3. Pages 배포 완료 후 사이트를 열고 `Ctrl + Shift + R`로 강력 새로고침합니다.
4. 페이지 하단 버전이 `v0.9.1`로 표시되는지 확인합니다.

`Code.gs`는 완전한 소스 스냅샷을 위해 패키지에 포함되어 있지만, 이 버전에서는 변경되지 않았습니다. 기존 Apps Script에 다시 붙여넣을 필요가 없습니다.

## 검사 범위

자바스크립트 문법, CSS/HTML 자산의 버전 문자열, manifest JSON, ZIP 구성을 확인했습니다. 실제 게시판이 연결된 브라우저에서 시각적 QA 또는 라이브 Apps Script 테스트는 수행하지 않았습니다.
